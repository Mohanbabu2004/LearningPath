1. Introduction to R

R is a programming language widely used for statistics, data analysis and data visualization. 

print("Hello R")

2. R Basics

R programs can be executed using simple commands. 

x <- 10
y <- 20

print(x)
print(y)

3. Variables

Variables can be created using the assignment operator <-. 

name <- "Mohan"
age <- 21
marks <- 85

print(name)
print(age)
print(marks)

4. Data Types

Common R data types include numeric, character, logical and integer. 

name <- "Mohan"
age <- 21
marks <- 85.5
passed <- TRUE

print(name)
print(age)
print(marks)
print(passed)

5. Operators

R supports arithmetic and comparison operators. 

a <- 10
b <- 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)

6. Conditions

if and else are used to make decisions. 

age <- 18

if (age >= 18) {
    print("Eligible")
} else {
    print("Not Eligible")
}

7. Loops

Loops are used to repeat statements. 

for (i in 1:5) {
    print(i)
}

8. Functions

Functions are reusable blocks of R code. 

add <- function(a, b) {

    return(a + b)

}

print(add(10, 20))

9. Vectors

A vector stores multiple values of the same type. 

numbers <- c(10, 20, 30, 40, 50)

print(numbers)

print(numbers[1])

10. Lists

Lists can store different types of data. 

student <- list(
    name = "Mohan",
    age = 21,
    marks = 85
)

print(student$name)
print(student$age)

11. Matrices

Matrices store data in rows and columns. 

matrix_data <- matrix(
    c(1, 2, 3, 4),
    nrow = 2,
    ncol = 2
)

print(matrix_data)

12. Data Frames

Data frames are commonly used to store tabular data. 

students <- data.frame(
    name = c("Mohan", "Rahul"),
    age = c(21, 22)
)

print(students)

13. Statistics

R provides built-in functions for statistical calculations. 

marks <- c(70, 80, 90, 85, 75)

print(mean(marks))
print(median(marks))
print(max(marks))
print(min(marks))

14. Practice

Create a student data analysis program using vectors, data frames and statistical functions. 

marks <- c(80, 75, 90, 85, 70)

average <- mean(marks)

print("Average Marks:")
print(average)
