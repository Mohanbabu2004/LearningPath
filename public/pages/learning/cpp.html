1. Introduction to C++

C++ is a powerful general-purpose programming language that supports procedural and object-oriented programming.

Why Learn C++?

  • Supports Object-Oriented Programming
  • Useful for Data Structures and Algorithms
  • Used in competitive programming
  • Provides high performance

2. C++ Basics

A basic C++ program uses the main() function and the iostream library. 

#include <iostream>

using namespace std;

int main()
{
    cout << "Hello World";

    return 0;
}

3. Variables & Data Types

Variables are used to store values. 

int age = 20;

float marks = 85.5;

char grade = 'A';

bool passed = true;

Common Data Types

  • int
  • float
  • double
  • char
  • bool

4. Operators

Operators perform operations on values. 

int a = 10;
int b = 5;

cout << a + b;

5. Conditional Statements

Conditional statements allow a program to make decisions. 

int age = 20;

if(age >= 18)
{
    cout << "Adult";
}
else
{
    cout << "Minor";
}

6. Loops

Loops execute a block of code repeatedly. 

for(int i = 1; i <= 5; i++)
{
    cout << i << endl;
}

7. Functions

Functions allow us to reuse code. 

int add(int a, int b)
{
    return a + b;
}

int main()
{
    cout << add(10, 20);

    return 0;
}

8. Arrays

Arrays store multiple values of the same data type. 

int numbers[5] =
{
    10, 20, 30, 40, 50
};

cout << numbers[0];

9. Strings

C++ provides the string class for working with text. 

#include <iostream>
#include <string>

using namespace std;

int main()
{
    string name = "Learning Path";

    cout << name;

    return 0;
}

10. Object-Oriented Programming

C++ supports object-oriented programming. The main concepts are classes and objects. 

class Student
{
public:

    string name;

    void display()
    {
        cout << name;
    }
};

11. Inheritance

Inheritance allows one class to acquire properties of another class. 

class Animal
{
public:

    void eat()
    {
        cout << "Eating";
    }
};

class Dog : public Animal
{
public:

    void bark()
    {
        cout << "Barking";
    }
};

12. Polymorphism

Polymorphism means one interface can have multiple forms. 

class Animal
{
public:

    virtual void sound()
    {
        cout << "Animal sound";
    }
};

class Dog : public Animal
{
public:

    void sound()
    {
        cout << "Dog barks";
    }
};
