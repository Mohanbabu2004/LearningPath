1. Introduction to JavaScript

JavaScript is a programming language used to make websites interactive and dynamic. 

console.log("Hello JavaScript");

2. JavaScript Basics

JavaScript code can be written inside an HTML <script> tag. 

<script>
    console.log("Hello World");
</script>

3. Variables & Data Types

JavaScript uses let, const and var to create variables. 

let name = "Mohan";
let age = 21;
let student = true;

console.log(name);
console.log(age);
console.log(student);

4. Operators

Operators are used to perform calculations and comparisons. 

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

5. Conditions

if and else are used to make decisions. 

let age = 18;

if (age >= 18) {
    console.log("Eligible");
} else {
    console.log("Not Eligible");
}

6. Loops

Loops are used to repeat a block of code. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

7. Functions

A function is a reusable block of code. 

function add(a, b) {
    return a + b;
}

console.log(add(10, 20));

8. Arrays

Arrays store multiple values in one variable. 

let languages = [
    "C",
    "C++",
    "Python",
    "JavaScript"
];

console.log(languages[0]);

9. Objects

Objects store data using key-value pairs. 

let student = {
    name: "Mohan",
    age: 21,
    course: "CSE-AI"
};

console.log(student.name);

10. Strings

Strings are used to store text. 

let message = "Learning JavaScript";

console.log(message);
console.log(message.length);
console.log(message.toUpperCase());

11. DOM

DOM allows JavaScript to access and change HTML elements. 

document.getElementById("title")
    .innerHTML = "Learning JavaScript";

12. Events

Events allow JavaScript to respond to user actions such as button clicks. 

function showMessage() {
    alert("Hello from JavaScript!");
}

13. Practice

Practice JavaScript programs and improve your programming skills. 

let number = 10;

if (number % 2 === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}
