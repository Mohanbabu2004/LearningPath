1. Introduction to Ruby

Ruby is a high-level programming language designed to be simple and easy to read. 

puts "Hello Ruby"

2. Ruby Basics

Ruby programs can be written using simple statements. 

puts "Welcome to Learning Path"

puts "Learn Ruby Easily"

3. Variables

Ruby variables do not require explicit type declarations. 

name = "Mohan"
age = 21
marks = 85

puts name
puts age
puts marks

4. Data Types

Ruby supports strings, integers, floats, booleans and arrays. 

name = "Mohan"
age = 21
marks = 85.5
student = true

puts name
puts age
puts marks
puts student

5. Operators

Operators are used to perform calculations. 

a = 10
b = 5

puts a + b
puts a - b
puts a * b
puts a / b

6. Conditions

if and else are used to make decisions. 

age = 18

if age >= 18
    puts "Eligible"
else
    puts "Not Eligible"
end

7. Loops

Ruby provides several ways to repeat code. 

for i in 1..5
    puts i
end

8. Methods

Methods are reusable blocks of Ruby code. 

def add(a, b)

    return a + b

end

puts add(10, 20)

9. Arrays

Arrays store multiple values. 

languages = [
    "C",
    "C++",
    "Python",
    "Ruby"
]

puts languages[0]

10. Hashes

Hashes store data using key-value pairs. 

student = {
    "name" => "Mohan",
    "age" => 21
}

puts student["name"]

11. Strings

Ruby provides many methods for working with strings. 

message = "Learning Ruby"

puts message
puts message.length
puts message.upcase

12. Classes & Objects

Ruby supports object-oriented programming using classes. 

class Student

    def initialize(name)
        @name = name
    end

    def display
        puts @name
    end

end

student = Student.new("Mohan")

student.display

13. Inheritance

A class can inherit methods from another class. 

class Animal

    def sound
        puts "Animal sound"
    end

end


class Dog < Animal

    def bark
        puts "Dog barks"
    end

end


dog = Dog.new

dog.sound
dog.bark

14. Practice

Create a Ruby student management program using classes, arrays and methods. 

class Student

    def initialize(name, age)
        @name = name
        @age = age
    end

    def display
        puts @name
        puts @age
    end

end

student = Student.new("Mohan", 21)

student.display
