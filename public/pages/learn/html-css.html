1. Introduction

HTML is used to create the structure of a webpage. CSS is used to design and style the webpage. 

<h1>Welcome to Learning Path</h1>

<p>Learn programming easily.</p>

2. HTML Basics

HTML uses tags to create webpage elements. 

<html>
<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

</body>
</html>

3. Headings & Paragraphs

HTML provides headings from h1 to h6 and paragraph elements using p. 

<h1>Main Heading</h1>

<h2>Sub Heading</h2>

<p>
    This is a paragraph.
</p>

4. Links & Images

The a tag creates links and the img tag displays images. 

<a href="https://example.com">
    Visit Website
</a>

<img src="image.jpg" alt="My Image">

5. Lists

HTML supports ordered and unordered lists. 

<ul>
    <li>C</li>
    <li>C++</li>
    <li>Python</li>
</ul>

<ol>
    <li>HTML</li>
    <li>CSS</li>
</ol>

6. Tables

Tables are used to display information in rows and columns. 

<table border="1">

    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Mohan</td>
        <td>21</td>
    </tr>

</table>

7. Forms

Forms collect information from users. 

<form>

    <label>Name</label>

    <input type="text"
           placeholder="Enter your name">

    <button type="submit">
        Submit
    </button>

</form>

8. CSS Basics

CSS is used to style HTML elements. 

h1 {
    color: blue;
    font-size: 30px;
}

p {
    color: gray;
}

9. CSS Selectors

Selectors identify the HTML elements that CSS should style. 

/* Element selector */

p {
    color: red;
}

/* Class selector */

.title {
    color: blue;
}

/* ID selector */

#main {
    background: white;
}

10. Colors & Fonts

CSS can change colors, fonts and text appearance. 

body {
    background-color: white;
    color: black;
    font-family: Arial;
}

h1 {
    color: blue;
}

11. Box Model

The CSS box model contains content, padding, border and margin. 

.card {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
    margin: 20px;
}

12. Flexbox

Flexbox makes it easier to arrange elements in rows and columns. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

13. Responsive Design

Responsive design makes websites work properly on computers, tablets and mobile phones. 

@media (max-width: 600px) {

    h1 {
        font-size: 25px;
    }

    .container {
        flex-direction: column;
    }

}
