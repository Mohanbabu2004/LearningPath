1. Introduction to Java

Java is a popular object-oriented programming language used to build desktop applications, web applications, Android applications and enterprise software.

Why Learn Java?

  • Object-oriented programming
  • Platform independent
  • Used in Android development
  • Strongly typed programming language

2. Java Basics

A simple Java program starts from the main() method. 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }
}

3. Variables & Data Types

Java requires variables to have a declared data type. 

int age = 22;

double marks = 85.5;

char grade = 'A';

boolean passed = true;

String name = "Mohan";

Common Data Types

  • int
  • float
  • double
  • char
  • boolean
  • String

4. Operators

Operators perform calculations and comparisons. 

int a = 10;
int b = 5;

System.out.println(a + b);
System.out.println(a - b);
System.out.println(a * b);
System.out.println(a / b);

5. Conditional Statements

if, else if and else are used for decision making. 

int age = 20;

if(age >= 18) {

    System.out.println("Adult");

} else {

    System.out.println("Minor");
}

6. Loops

Loops execute a block of code repeatedly. 

for(int i = 1; i <= 5; i++) {

    System.out.println(i);

}

7. Arrays

Arrays store multiple values of the same type. 

int[] numbers = {
    10, 20, 30, 40, 50
};

System.out.println(numbers[0]);

8. Methods

Methods contain reusable blocks of code. 

static int add(int a, int b) {

    return a + b;
}

public static void main(String[] args) {

    System.out.println(add(10, 20));

}

9. Classes & Objects

A class is a blueprint for creating objects. 

class Student {

    String name;

    void display() {

        System.out.println(name);

    }
}

10. Inheritance

Inheritance allows one class to inherit properties and methods from another class. 

class Animal {

    void eat() {

        System.out.println("Eating");

    }
}

class Dog extends Animal {

    void bark() {

        System.out.println("Barking");

    }
}

11. Polymorphism

Polymorphism allows the same method name to behave differently. 

class Animal {

    void sound() {

        System.out.println("Animal sound");

    }
}

class Dog extends Animal {

    void sound() {

        System.out.println("Dog barks");

    }
}

12. Exception Handling

Exception handling allows programs to handle runtime errors safely. 

try {

    int result = 10 / 0;

} catch (Exception e) {

    System.out.println("Error occurred");

}
