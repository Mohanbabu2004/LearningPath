1. Introduction to C

C is a general-purpose programming language used to develop applications, operating systems, embedded systems and many other software systems.

Why Learn C?

  • Easy to understand programming fundamentals
  • Helps understand memory and pointers
  • Useful for Data Structures and Algorithms
  • Foundation for C++

2. C Programming Basics

A simple C program starts with the main() function. 

#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

The printf() function is used to display output on the screen.

3. Variables & Data Types

Variables are used to store data in memory. 

int age = 20;

float marks = 85.5;

char grade = 'A';

Common Data Types

  • int
  • float
  • double
  • char

4. Operators

Operators are used to perform operations on values. 

int a = 10;
int b = 5;

printf("%d", a + b);

Common operators include +, -, *, / and %.

5. Conditional Statements

Conditions allow a program to make decisions. 

int age = 20;

if(age >= 18)
{
    printf("Adult");
}
else
{
    printf("Minor");
}

6. Loops

Loops are used to execute a block of code repeatedly. 

for(int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}

7. Functions

Functions allow us to divide a program into reusable blocks. 

int add(int a, int b)
{
    return a + b;
}

8. Arrays

Arrays store multiple values of the same data type. 

int numbers[5] = {
    10, 20, 30, 40, 50
};

9. Strings

A string is a sequence of characters. 

char name[] = "Learning Path";

printf("%s", name);

10. Pointers

A pointer stores the memory address of another variable. 

int x = 10;

int *p = &x;

printf("%d", *p);

11. Structures

Structures allow us to group different data types together. 

struct Student
{
    int age;
    char grade;
};
