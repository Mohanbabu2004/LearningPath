1. Introduction to CUDA

CUDA is a parallel computing platform and programming model developed by NVIDIA. 

#include <stdio.h>

int main() {

    printf("Hello CUDA\n");

    return 0;
}

2. GPU Computing

GPUs can perform many calculations simultaneously, making them useful for parallel computing. 

CPU
  |
  └── Few powerful cores

GPU
  |
  ├── Many smaller cores
  ├── Parallel execution
  └── High throughput

3. CUDA Basics

CUDA programs can contain code that runs on the CPU and code that runs on the GPU. 

#include <stdio.h>

__global__ void hello() {

    printf("Hello from GPU\n");

}

int main() {

    hello<<<1, 1>>>();

    cudaDeviceSynchronize();

    return 0;
}

4. CUDA Kernels

A kernel is a function that executes on the GPU. The __global__ keyword is commonly used for kernels. 

__global__ void myKernel() {

    printf("Running on GPU\n");

}

5. Threads

Threads are individual execution units used to perform parallel work. 

__global__ void showThread() {

    printf(
        "Thread ID: %d\n",
        threadIdx.x
    );

}

6. Thread Blocks

Threads are organized into blocks. 

__global__ void showThread() {

    printf(
        "Thread: %d\n",
        threadIdx.x
    );

}

int main() {

    showThread<<<1, 4>>>();

    cudaDeviceSynchronize();

    return 0;
}

11. Parallel Programming

CUDA allows many threads to perform similar operations at the same time. 

__global__ void add() {

    int id = threadIdx.x;

    printf(
        "Processing element %d\n",
        id
    );
}

12. Vector Addition

Vector addition is a common beginner CUDA example. 

__global__ void vectorAdd(
    int *a,
    int *b,
    int *c
) {

    int id = threadIdx.x;

    c[id] = a[id] + b[id];

}

13. Error Handling

CUDA functions can return error codes that should be checked during development. 

cudaError_t error;

error = cudaGetLastError();

if (error != cudaSuccess) {

    printf(
        "CUDA Error: %s\n",
        cudaGetErrorString(error)
    );

}
