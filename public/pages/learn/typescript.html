1. Introduction to TypeScript

TypeScript is a programming language that builds on JavaScript and adds static type checking. 

let message: string = "Hello TypeScript";

console.log(message);

2. TypeScript Basics

TypeScript allows you to specify the type of a variable. 

let name: string = "Mohan";
let age: number = 21;
let student: boolean = true;

3. Variables & Types

Common TypeScript types include string, number, boolean and any. 

let course: string = "CSE-AI";
let marks: number = 85;
let passed: boolean = true;

4. Arrays

TypeScript allows you to define the type of array elements. 

let numbers: number[] = [10, 20, 30];

let languages: string[] = [
    "C",
    "Python",
    "JavaScript"
];

console.log(numbers);

5. Objects

Objects can contain properties with specific types. 

let student: {
    name: string;
    age: number;
} = {
    name: "Mohan",
    age: 21
};

console.log(student.name);

6. Functions

TypeScript allows you to define parameter and return types. 

function add(
    a: number,
    b: number
): number {

    return a + b;
}

console.log(add(10, 20));

7. Interfaces

Interfaces define the structure of objects. 

interface Student {
    name: string;
    age: number;
}

let student: Student = {
    name: "Mohan",
    age: 21
};

console.log(student);

8. Classes

Classes are used to create objects using object-oriented programming. 

class Student {

    name: string;

    constructor(name: string) {
        this.name = name;
    }

    display(): void {
        console.log(this.name);
    }
}

let s1 = new Student("Mohan");

s1.display();

9. Inheritance

A class can inherit properties and methods from another class. 

class Animal {

    sound(): void {
        console.log("Animal sound");
    }
}

class Dog extends Animal {

    bark(): void {
        console.log("Dog barks");
    }
}

let dog = new Dog();

dog.sound();
dog.bark();

10. Generics

Generics allow reusable code that works with different types. 

function display<T>(value: T): T {

    return value;
}

console.log(display<number>(10));

console.log(
    display<string>("Hello")
);

11. Union Types

Union types allow a variable to contain more than one type. 

let id: number | string;

id = 101;

id = "STUDENT101";

console.log(id);

12. Enums

Enums define a set of named constants. 

enum Direction {
    North,
    South,
    East,
    West
}

let direction: Direction = Direction.North;

console.log(direction);

13. DOM

TypeScript can be used to interact with HTML DOM elements. 

const title =
    document.getElementById("title");

if (title) {
    title.textContent =
        "Learning TypeScript";
}
