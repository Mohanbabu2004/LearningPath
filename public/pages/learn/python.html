1. Introduction to Python

Python is a high-level, interpreted programming language known for its simple syntax and readability.

Why Learn Python?

  • Easy syntax for beginners
  • Used in web development
  • Used in Data Science and Machine Learning
  • Used in Artificial Intelligence

2. Python Basics

Python programs can be written with very simple syntax. 

print("Hello World")

The print() function displays output.

3. Variables & Data Types

Python variables do not require an explicit data type declaration. 

name = "Mohan"

age = 22

marks = 85.5

passed = True

Common Data Types

  • int
  • float
  • str
  • bool

4. Operators

Operators are used to perform calculations and comparisons. 

a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)

5. Conditional Statements

if, elif and else are used to make decisions. 

age = 20

if age >= 18:
    print("Adult")
else:
    print("Minor")

6. Loops

Loops execute code repeatedly. 

for i in range(1, 6):
    print(i)

Python also provides the while loop.

7. Functions

Functions are reusable blocks of code. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

8. Lists

Lists store multiple values and are mutable. 

numbers = [10, 20, 30, 40]

print(numbers[0])

numbers.append(50)

9. Tuples

Tuples store multiple values and cannot normally be changed after creation. 

numbers = (10, 20, 30)

print(numbers[0])

10. Dictionary

Dictionaries store data using key-value pairs. 

student = {
    "name": "Mohan",
    "age": 22,
    "course": "CSE-AI"
}

print(student["name"])

11. Sets

Sets store unique values. 

numbers = {10, 20, 30, 30}

print(numbers)

12. Object-Oriented Programming

Python supports object-oriented programming using classes and objects. 

class Student:

    def __init__(self, name):
        self.name = name

    def display(self):
        print(self.name)


student = Student("Mohan")

student.display()
