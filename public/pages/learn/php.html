1. Introduction to PHP

PHP is a server-side scripting language commonly used to build dynamic websites and web applications. 

<?php

echo "Hello PHP";

?>

2. PHP Basics

PHP code is normally written inside <?php and ?> tags. 

<?php

echo "Welcome to Learning Path";

?>

3. Variables

PHP variables start with the dollar symbol. 

<?php

$name = "Mohan";
$age = 21;

echo $name;
echo $age;

?>

4. Data Types

PHP supports strings, integers, floats, booleans and arrays. 

<?php

$name = "Mohan";
$age = 21;
$marks = 85.5;
$student = true;

?>

5. Operators

Operators are used for calculations and comparisons. 

<?php

$a = 10;
$b = 5;

echo $a + $b;
echo $a - $b;
echo $a * $b;
echo $a / $b;

?>

6. Conditions

if and else statements are used to make decisions. 

<?php

$age = 18;

if ($age >= 18) {
    echo "Eligible";
} else {
    echo "Not Eligible";
}

?>

7. Loops

Loops execute code repeatedly. 

<?php

for ($i = 1; $i <= 5; $i++) {
    echo $i;
}

?>

8. Functions

Functions are reusable blocks of code. 

<?php

function add($a, $b) {
    return $a + $b;
}

echo add(10, 20);

?>

9. Arrays

Arrays store multiple values in one variable. 

<?php

$languages = array(
    "C",
    "C++",
    "Python",
    "PHP"
);

echo $languages[0];

?>

10. Strings

Strings are used to store text. 

<?php

$name = "Learning Path";

echo strlen($name);
echo strtoupper($name);

?>

11. Forms

PHP can process data submitted through HTML forms. 

<form method="post">

    <input
        type="text"
        name="name"
        placeholder="Enter name">

    <button type="submit">
        Submit
    </button>

</form>

<?php

if ($_SERVER["REQUEST_METHOD"] == "POST") {

    echo $_POST["name"];

}

?>

12. PHP & MySQL

PHP can connect to MySQL databases using MySQLi or PDO. 

<?php

$conn = new mysqli(
    "localhost",
    "root",
    "",
    "learningpath"
);

if ($conn->connect_error) {
    die("Connection failed");
}

echo "Database Connected";

?>

13. Sessions

Sessions are commonly used to store user information between different pages. 

<?php

session_start();

$_SESSION["username"] = "Mohan";

echo $_SESSION["username"];

?>
