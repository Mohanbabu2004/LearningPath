# 📚 LearningPath – Complete Coding Learning Platform

Learn Programming the **Easy Way**.

## 🚀 Project Overview
LearningPath is a comprehensive coding platform featuring:
- **12 Programming Languages**: C, C++, Python, TypeScript, JavaScript, Java, R, CUDA, Ruby, PHP, HTML, CSS.
- **Interactive Quizzes**: 100 Unique Questions per level (Beginner, Intermediate, Advanced) with zero question repetition.
- **Pass/Fail Threshold**: 35 Marks required to unlock next levels.
- **Detailed Progress & Roadmap**: Visual progress bar tracking across courses and profile pages.

## 🛠️ Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Server**:
   ```bash
   npm start
   ```

3. **Open Browser**:
   Navigate to `http://localhost:3000`
